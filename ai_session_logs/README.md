# AI Session Logs

This directory contains supporting evidence of AI-assisted development during the Easy Rent Bali technical assessment.

## Purpose

The session logs document how AI tools were used throughout the development process, including implementation suggestions, technical reviews, debugging, and iterative improvements.

## Contents

- `STEERING_AUDIT.md` — Summary of AI-assisted iterations, identified issues, candidate corrections, and verification results.
- Conversation evidence — Actual ChatGPT prompt and response excerpts supporting the development process.

## Documentation Guidelines

1. Preserve actual conversation excerpts and relevant timestamps.
2. Include the original prompts and AI responses where they demonstrate technical iterations.
3. Highlight candidate decisions, corrections, and validation activities.
4. Keep sufficient context to demonstrate how AI-generated suggestions were reviewed.
5. Do not fabricate conversations, timestamps, or test results.
6. Remove sensitive credentials and personal information before sharing evidence.

## Verification

All reported implementation and testing results should correspond to commands executed in the local development environment.

AI-generated code was reviewed and validated by the candidate before being included in the assessment project.
